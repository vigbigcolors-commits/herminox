## Comment reply playbook (be human)

PH rewards **fast, real conversation** — not polished corporate replies.  
Goal: every comment gets a personal answer. Sound like a maker at a coffee shop, not a support bot.

### Golden rules
1. **Reply to everyone** — even “congrats!” (1–2 warm sentences + soft question).
2. **Speed:** first 4 hours → under 15–30 min. Rest of day → under 1 hour when awake.
3. **Never ask for upvotes.** Never “if you like it please upvote.”
4. **Never copy-paste the same paragraph** to 5 people. Change the first line every time.
5. **Name the thing they said** (“the holiday return window point — yes…”).
6. **Admit limits** honestly (fees change, 3P sellers, not Seller Central login).
7. **End with one easy question** so the thread stays alive.
8. English on PH. Short paragraphs. No emoji spam (1 is fine).

### Voice checklist (before you hit Reply)
- [ ] Mentions *their* words (not generic “Thanks for the feedback!”)
- [ ] One concrete fact or link (tool URL, `/privacy/`, `/embed/`)
- [ ] Honest if something is missing / on roadmap
- [ ] No buzzwords: “synergy”, “delighted”, “leverage”, “game-changer”
- [ ] Sounds like you’d say it on voice chat

### Reply formula (30–90 seconds to write)
```
1. Hook their point (1 line)
2. Answer / story (2–4 lines)
3. Optional: link to the exact tool
4. One specific question back
```

### Ready replies (customize the first line every time)

#### A) Congrats / “looks cool”
```
Thanks — that means a lot on launch day.

If you try one tool, I’d start with FBA Profit or ACoS breakeven (seller) / unit price (buyer). Curious: are you more on the selling side or the buying side?
```

#### B) “Is it really free / what’s the catch?”
```
No catch on the calculators — free, no account, no “email to unlock.”

I use light page analytics (GA) for traffic only; the numbers you type stay in your browser. Privacy page: https://herminox.com/privacy/

If you spot anything that feels shady, tell me bluntly — I’ll fix it.
```

#### C) “How accurate are the FBA fees?”
```
They’re based on Amazon’s published US fee schedules (incl. the 2026 fuel surcharge toggle) — good enough to kill bad SKUs fast.

They’re not a substitute for Fee Preview in your own Seller Central. Amazon can change rates and some programs differ by account.

If your category is weird (apparel tiers, jewelry, etc.), try the category dropdown on https://herminox.com/sellers/fba-calculator/ and tell me if a band looks off.
```

#### D) “Are you affiliated with Amazon?”
```
Nope — independent. Not endorsed by Amazon.

I cite public fee language and always say: confirm in Seller Central before you wire a supplier. That disclaimer is on the tools on purpose.
```

#### E) Privacy / “do you store my numbers?”
```
Calculator inputs are not sent to our servers — five tools are fully client-side; the return tracker keeps entries in your browser localStorage only.

We do run aggregate page analytics. Details: https://herminox.com/privacy/

Happy to answer any specific “what leaves my machine?” question.
```

#### F) Feature request (API, Chrome extension, EU marketplace, etc.)
```
Love this — [repeat their ask in your words].

Not built yet. Next on my list after launch week is [closest honest item: more prefills / embeds / guides]. An API is later; I want the math to stay boringly correct first.

Would you use that weekly, or is it more of a nice-to-have?
```

#### G) “I use Jungle Scout / Helium / Sellerboard…”
```
Those are great for research and ops — different job.

Herminox is the “run the margin / ACoS / payback math in 30 seconds without another login” layer. Use both: research there, sanity-check cash math here.

What’s the one number you still calculate in a spreadsheet today?
```

#### H) Criticism / “UI is plain” / “I don’t get it”
```
Fair — thanks for saying it straight.

[If UI:] I’m optimizing for clarity over chrome; if a specific screen felt confusing, which one?

[If math:] Point me at the inputs you used and what you expected — I’ll check the logic. We also keep an audit script for the calculators.

Concrete notes beat vague ones; roast away.
```

#### I) Seller-specific: ACoS / TACoS
```
Breakeven ACoS here is basically your pre-ad margin %. TACoS drops when organic share rises — there’s a slider for that.

Tool: https://herminox.com/sellers/acos-breakeven/

Do you usually target a % of breakeven, or a fixed ACoS number from habit?
```

#### J) Inventory / cash recovery
```
Important detail: units-to-recover divides PO cash by (sell − Amazon fees), not by profit. Using profit overstates how many units you need.

https://herminox.com/sellers/inventory-breakeven/

What’s a typical PO size you’re deciding on right now?
```

#### K) Buyer tools
```
Unit price = shrinkflation / pack-size fights. Cost per use = “cheap boots vs quality boots.” Return tracker = holiday windows + locked capital.

Which headache hits you more often — comparing packs, or missing return deadlines?
```

- “Honestly not yet.”
- “Good catch.”
- “I’d start with…”
- “Roast away.”
- “Tell me if a band looks off.”

### Phrases that sound like a bot (avoid)
- “Thank you for your valuable feedback!”
- “We’re thrilled to hear…”
- “Please don’t hesitate to reach out.”
- “As mentioned above…”
- “Our team will look into this.” (you are the team)
- “Kindly upvote if…”

### If you freeze
Type only this structure:
1. “Thanks — [their exact topic].”
2. One true sentence.
3. “Curious: [one question]?”

Ship it. Perfect is slower than human.
